## ⚡ Vercel Deployment Instructions (GitHub to Vercel)

This repository is pre-configured with `vercel.json` and a production-ready, fully responsive **Telegram Mini App / Single-Page Web Application** (`index.html`) using Tailwind CSS and Telegram WebApp SDK.

### Steps to Deploy to Vercel:

1. **Push to GitHub**:
   - In AI Studio, open the top-right settings/menu and click **"Export to GitHub"** (or push this repository using Git).
2. **Open Vercel**:
   - Go to [https://vercel.com/new](https://vercel.com/new) and log in with your GitHub account.
3. **Import Project**:
   - Select your `slk-buy-group` repository from the list.
4. **Deploy**:
   - Keep all default settings (Framework Preset: **Other** / Static).
   - Click **Deploy**.
   - Within 10 seconds, Vercel will give you a live production URL (e.g. `https://slk-buy-group.vercel.app`)!

## 🤖 Connect to Telegram Bot (Mini App / WebApp)

1. Open Telegram and search for [@BotFather](https://t.me/BotFather).
2. Send `/mybots` and choose your bot.
3. Click **Bot Settings** -> **Menu Button** -> **Configure menu button**.
4. Send your Vercel URL: `https://your-app-name.vercel.app`
5. Set the button text to: `🛒 SLK BUY GROUP` or `🔥 Open Store`.

Users will now be able to open the app directly inside Telegram with full native integration!
